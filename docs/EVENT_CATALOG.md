# Event catalog

| Event | 用途 |
|---|---|
| `session_started` | アクセス数 |
| `page_view` | PV |
| `offer_impression` | 広告・予約候補表示 |
| `affiliate_click` | CTR |
| `conversion` | CVR・売上 |
| `concierge_started` | AI準備開始 |
| `concierge_completed` | AI準備完了 |
| `checklist_completed` | 準備完了 |
| `notification_subscribed` | 通知登録 |
| `booking_started` | 予約開始 |
| `error` | 品質ガードレール |

許可属性: `campaign`, `placement`, `category`, `itemId`, `experiment`, `variant`, `contentClass`。
